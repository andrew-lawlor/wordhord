Two parallel texts for milestone 3.

- Beowulf, lines 1-11: Old English, and Gummere (1910). Aligned line to line.
- Völuspá, stanza 1: Old Norse (8 half-lines), and Bellows (1923, 4 long lines). Aligned stanza to stanza.

The English is public domain. The Old English and Old Norse were typed from memory of the standard texts: check them against Klaeber (1922) and Bugge (1867) before relying on them.

Names are tagged in all four, with the same keys in original and translation: `spear-danes`, `scyld`, `heimdallr`, `odinn`. Each book has a `names.toml`. Valfather and Valfǫðr both resolve to Óðinn.
