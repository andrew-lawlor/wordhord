# Fonts

Bundled, so a book typesets the same on any machine. Each compiled book pins its fonts by hash.

| Font | Files | Licence |
|---|---|---|
| [Junicode](https://github.com/psb1558/Junicode-font) 2.226, by Peter S. Baker | `junicode/` | SIL Open Font License 1.1 (`junicode/OFL.txt`) |
| DejaVu Serif, for the few characters Junicode lacks (⋮) | `dejavu/` | Bitstream Vera licence, public domain changes (`dejavu/LICENSE`) |

Junicode is made for medievalists: it has þ, ð, ǫ, æ, œ and the rest of what Old Norse, Old English and Middle English need. Every character in `books/` is in Junicode except U+22EE (⋮).
| DejaVu Sans Mono, for code | `dejavu/` | The same Bitstream Vera licence (`dejavu/LICENSE`) |
