# Books

Converted editions, each with its own licence. The code in this repository is GPL-3.0-or-later; these texts are not.

| Book | Edition | Licence |
|---|---|---|
| `comedy-longfellow` | Henry Wadsworth Longfellow, *The Divine Comedy* (1867), translated line for line, with his 2,109 notes. From the Standard Ebooks edition. Cantos are numbered as Dante's: `inf.1.1` is *Inferno* 1.1. | Public domain |
| `odyssey-bryant` | William Cullen Bryant, *The Odyssey* (1871), in blank verse. From the Standard Ebooks edition. Bryant's lines aren't Homer's, so it has no line references. | Public domain |
| `edda-bellows` | Henry Adams Bellows, *The Poetic Edda* (1923), from Project Gutenberg #73533 | Public domain |
| `edda-pettit` | Edward Pettit's English translation, with his footnotes, from the same edition. Aligns stanza for stanza with `edda-pettit-non`. | [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/), © 2023 Edward Pettit. Converted to this format; text unchanged. |
| `edda-pettit-non` | The Old Norse text of Edward Pettit, *The Poetic Edda: A Dual-Language Edition* (Open Book Publishers, 2023), [doi:10.11647/OBP.0308](https://doi.org/10.11647/OBP.0308) | [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/), © 2023 Edward Pettit. Converted to this format; text unchanged. |

Each folder's `book.toml` records its source and licence. Recipes for converting them are in `recipes/`.

Bellows is numbered after Hildebrand–Gering (1904), not Pettit, so it doesn't align with `edda-pettit-non` yet: that needs a concordance between the two numberings.
